# 10-Day Master Timeline (3 workstreams, 1 submission)

**Assumption:** about 4 to 5 focused hours a day. Day 1 = Sun Oct 4, Day 10 = Tue Oct 13. The real deadline is **Oct 23, 12:00 pm PT (about 12:30 am IST on Oct 24)**, so you keep roughly 10 spare days as a safety buffer. Shift the dates if you start later.

## The three workstreams

| Code | Workstream | What it really is |
| --- | --- | --- |
| **A** | Main: Alexa+ track | Family Admin Agent (MCP server + simulated Alexa+ chat) |
| **B** | AWS Builder mini challenge | An add-on to project A. You use **Kiro Crew** (AWS's open-source agent workspace) while building A, and document it |
| **C** | Open Source mini challenge | One meaningful **pull request** to an existing public repo (no separate project) |

B is not a separate project. The rules say mini challenges build on top of your primary submission.

## Daily routine (keeps all 3 moving)

1. 30 min: PR and review replies (workstream C)
2. 3 hrs: main build (A), with Kiro Crew helping (B)
3. 15 min: update the friction log (anything that confused you, and how you fixed it)

## Cut lines (what to drop if you fall behind)

1. First to go: MCP Apps dashboard card (Day 8)
2. Second: the Agent Skill file
3. Third: the multi-step `plan_scheme_application` tool becomes a simple checklist
4. **Never cut:** tests, README, license, demo video, product feedback, friction log

## Gates (check yourself)

- End of Day 3: 6 tools work in Inspector
- End of Day 5: PR is open **and** eligibility works end to end
- End of Day 7: simulator talks to the server
- End of Day 9: a friend (or you, on a clean folder) can run it from the README alone

## Use the spare days well

Do not use the spare days to add features. Use them to re-record a better video, fix README gaps, and finish the PR conversation. **Aim to submit by Oct 20.**

## Submission checklist (Day 10)

- [ ] Text description
- [ ] Public repo with license (detectable in the About section)
- [ ] Demo video link (YouTube or Vimeo, public, English, under 3 min)
- [ ] Product feedback (5 questions, per tool used)
- [ ] Track: Alexa+
- [ ] Mini challenges: AWS Builder + Open Source (extra fields)
- [ ] Friction log (optional, but worth up to a 10% bonus)
- [ ] Fake data only, no real IDs, no third-party logos or copyrighted music
